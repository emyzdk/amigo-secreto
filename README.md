# 🎁 Amigo Secreto

## 🧩 Sobre o Projeto
O "Amigo Secreto" é uma aplicação front-end desenvolvida para simular a lógica de sorteio de participantes em uma tradicional troca de presentes. Este projeto foi criado como parte dos exercícios propostos nos cursos de desenvolvimento web da Alura, focando na aplicação de algoritmos e na integração fluida entre as tecnologias front-end. O objetivo principal é praticar a manipulação de arrays e implementar uma lógica de sorteio robusta utilizando JavaScript, que garante que cada participante seja sorteado de forma aleatória sem tirar a si mesmo.
